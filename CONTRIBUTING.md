# Contributing to Lyceum

Contributions are welcome: bug reports, translations, documentation and code.

## Before you open a pull request

1. **Sign the CLA.** All contributions require the [Contributor License Agreement](CLA.md). You keep your copyright. The CLA lets the maintainer keep offering official builds through app stores (whose terms are incompatible with the AGPL alone) and keep the project sustainable. The CLA bot will ask you to sign on your first pull request.
2. **Run the quality checks** described in [docs](docs/index.md) (lint, type check and tests).
3. **Keep changes focused.** One feature or fix per pull request.
